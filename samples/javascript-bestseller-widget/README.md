# JavaScript 베스트셀러 위젯

예스24 베스트셀러 TOP 10을 카드 목록으로 보여주는 임베드형 위젯 샘플입니다.
프레임워크·빌드 도구 없이 **단일 HTML + Node.js 내장 모듈 프록시**로 구성되어 `npm install` 이 필요 없습니다.

| 파일 | 역할 |
|---|---|
| `index.html` | 위젯 UI (CSS·JS 인라인, 카테고리 선택 + TOP 10 카드) |
| `proxy.js` | 정적 서빙 + 오픈 API 프록시 (서버 측 `X-Api-Key` 주입) |
| `sample-data.json` | 데모 모드용 가상 데이터 (실제 응답과 동일한 스키마) |

## 왜 브라우저에서 직접 호출하지 않나요?

1. **CORS** — 오픈 API는 허용된 오리진의 브라우저 호출만 받습니다. 임의의 사이트에서 `apis.yes24.com` 을 직접 `fetch` 하면 차단됩니다.
2. **API 키 보호** — 브라우저 코드에 키를 넣으면 페이지를 여는 모든 사람에게 키가 노출됩니다.

그래서 위젯은 자기 서버(`proxy.js`)를 경유하고, 키는 서버 환경변수에만 둡니다.
**실서비스에 임베드할 때도 같은 구조(자체 서버 프록시)를 사용하세요.**

## 실행 방법

```powershell
# 데모 모드 — API 키 없이 바로 실행 (sample-data.json 표시, "데모 데이터" 배지)
node proxy.js

# 실서비스 모드 — 개발자센터(https://developers.yes24.com)에서 발급한 키 설정 후 실행
$env:YES24_API_KEY = "발급받은키"
node proxy.js
```

브라우저에서 <http://localhost:8787> 접속.

- 실서비스 모드에서는 카테고리 목록(`/v1/category/list`)도 실제 API에서 불러옵니다.
- 데모 모드의 도서·카테고리는 모두 **가상의 데이터**입니다.

## 환경변수

| 이름 | 필수 | 설명 |
|---|---|---|
| `YES24_API_KEY` | X | 미설정 시 데모 모드로 동작 |
| `YES24_API_BASE_URL` | X | 기본 `https://apis.yes24.com` |
| `PORT` | X | 기본 `8787` |
