# 오류 코드

예스24 오픈 API의 모든 오류 응답은 아래 공통 JSON 구조로 반환됩니다.

```json
{ "success": false, "errorCode": "AUTH_001", "message": "오류 메시지", "data": null }
```

## 인증 오류 (AUTH)

| 코드 | HTTP | 메시지 | 원인 및 해결 |
|---|---|---|---|
| `AUTH_001` | 401 | X-Api-Key 헤더가 없습니다. | 요청에 `X-Api-Key: {apiKey}` 헤더를 추가하세요. |
| `AUTH_002` | 401 | 유효하지 않은 API Key입니다. | 키 값이 올바른지 확인하세요. 폐기된 키 또는 비활성 계정의 키는 인증이 거부됩니다. |

## 호출 한도 초과 (RATE)

| 코드 | HTTP | 메시지 | 원인 및 해결 |
|---|---|---|---|
| `RATE_001` | 429 | 초당 호출 허용량을 초과했습니다. | 초당 호출 한도(5회)를 초과했습니다. `Retry-After` 헤더의 시간만큼 기다렸다가 재시도하세요. |
| `RATE_002` | 429 | 일일 호출 허용량을 초과했습니다. | 키별 일일 한도(5,000회)를 초과했습니다. 한도는 매일 자정(KST)에 초기화되며, 사용량은 개발자센터의 API 이용 현황에서 확인할 수 있습니다. |

## 파라미터 오류 (PARAM)

| 코드 | HTTP | 메시지 (예시) | 원인 및 해결 |
|---|---|---|---|
| `PARAM_001` | 400 | categoryId 파라미터를 입력하세요. | 필수 파라미터(categoryId)가 누락됐습니다. |
| `PARAM_002` | 400 | date 파라미터는 yyyy-MM-dd 형식이어야 합니다. | 날짜 형식이 잘못됐습니다. 예: `2026-06-01` |
| `PARAM_003` | 400 | query 파라미터를 입력하세요. | 필수 파라미터(query)가 누락됐습니다. |
| `PARAM_004` | 400 | 유효하지 않은 query 입니다. | 값 형식이 잘못됐습니다. ItemId 는 숫자, ISBN13 은 13자리 숫자인지 확인하세요. |
| `PARAM_005` | 400 | 유효하지 않은 sort 값입니다. | 각 API 문서에서 허용되는 `sort` 값을 확인하세요. |
| `PARAM_006` | 400 | 유효성 검사 실패 | 파라미터 타입과 값 범위를 확인하세요. (예: pageSize 1~100) |
| `PARAM_007` | 400 | Invalid request parameter. | 요청 경로·쿼리스트링이 허용 범위를 초과하거나 유효하지 않은 문자를 포함하고 있습니다. |

## 데이터 없음 (404)

| 코드 | HTTP | 메시지 | 발생 API |
|---|---|---|---|
| `CATEGORY_001` | 404 | 카테고리 결과가 없습니다. | 카테고리 목록 |
| `BEST_001` | 404 | 베스트셀러 결과가 없습니다. | 베스트셀러 전체 (실시간·종합·일별·월별·특가·스테디) |
| `NEW_001` | 404 | 신상품 결과가 없습니다. | 신상품 |
| `ATTN_001` | 404 | 주목할 신상품 결과가 없습니다. | 주목할 신상품 |
| `SEARCH_001` | 404 | 검색 결과가 없습니다. | 상품 검색 |
| `GOODS_001` | 404 | 상품 상세/목차 정보가 없습니다. | 상품 상세·목차 |
| `GOODS_002` | 404 | ISBN13에 해당하는 상품을 찾을 수 없습니다. | `searchType=ISBN13` 조회 전체 |
| `AUTHOR_404` | 404 | 작가 정보가 없습니다. | 작가 정보 |

## 서버 오류 (5xx)

| 코드 | HTTP | 메시지 | 원인 및 해결 |
|---|---|---|---|
| `INTERNAL_ERROR` | 500 | 서버 내부 오류가 발생했습니다. | 잠시 후 재시도하세요. 지속되면 발생 API·요청 파라미터·발생 시각과 함께 개발자센터로 문의하세요. |
| `UPSTREAM_UNAVAILABLE` | 503 | 외부 서비스가 일시적으로 사용할 수 없습니다. | 외부 연동 서비스 장애입니다. 잠시 후 재시도하고, 지속되면 공지사항을 확인하세요. |
